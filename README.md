# 史料 · 研究

现有史料数据库的极简界面改版。保留 Firebase 账户和课题数据结构，增加暖灰、石白与深炭色的阅读界面、富文本编辑、历史日期录入和草稿恢复。

## 本地查看

需要 Node.js 20 或更高版本。在本目录运行：

```sh
node scripts/serve.cjs --demo
```

打开 http://127.0.0.1:8766 。演示使用虚构示例与浏览器会话存储，服务器阻止连接真实数据库。退出浏览器会话后示例修改可能消失。演示不会创建真实账户。

正式本地入口：`node scripts/serve.cjs`，地址 http://127.0.0.1:8765 。此模式使用原有 Firebase 配置，需要真实账户与可用网络。不要通过双击 HTML 的方式启动。

## 使用要点

- 首页支持课题筛选、目录与卡片切换、继续上次研究；工作台支持列表、详细、阅读及时间轴视图。
- 日期可直接输入 `1937-07-07`、`1937年7月7日`、`19370707`；史料日期还支持 `1937`、`1937-07`、`约1937`、`1937至1945`、`不详`。可保留原始纪年文字。日历可以直接修改年份；不存在的日期会提示纠正。此功能不自动换算农历或民国纪年。
- 富文本支持标题、列表、引用、链接、上下标、颜色与高亮、对齐、表格、图片及图注、研究批注、查找替换。空白段落输入 `/` 打开插入菜单。表格或图片选中后显示对应操作。
- 原文和分析可以左右对照、全屏编辑。`Ctrl/Cmd+S` 保存史料，关闭编辑窗口会先保存本机草稿。
- 修改自动保存到本机 IndexedDB；联网后同步云端草稿。“本机恢复草稿”可找回中断编辑。草稿不等于正式保存的史料。
- 保存保留最近 10 次历史快照。多人或多窗口修改同一史料时，检测版本差异并提示比较。恢复版本后仍需确认保存。
- 删除进入回收站并提供短时撤销。JSON 导出保留结构化编辑内容、日期信息与版本；HTML 导出保留表格、图片和批注。CSV、Markdown 的原有纯文本导出不保留全部版式。

## 开发与验证

已提交可直接使用的编辑器构建产物，普通静态托管不需要安装依赖。修改编辑器源码后：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm test:browser
```

浏览器测试在 Windows 默认使用已安装的 Microsoft Edge；其他平台先运行 `pnpm exec playwright install chromium`。测试使用内存数据库并隔离外部网络，覆盖日期、编辑器往返转换、保存、历史版本、冲突、草稿恢复、导出与手机布局。测试通过不代表真实 Firebase 权限、网络故障和生产账户已完成联调。

## 数据兼容与边界

旧 HTML 首次编辑时转换为新编辑器支持的格式；首次保存旧条目时保留原文与分析的 `legacyBackup`。复杂或未知的旧格式不保证像素级还原。脚本和不安全内容会被移除，嵌入 iframe 转为原始来源链接。

本机上传图片会压缩后存入内容，不是独立云端图片管理服务。单张原始图片上限 5 MB；大量图片会增加数据库占用。研究批注为文内批注，不是自动排版的页底脚注。查找替换按文本片段工作，跨多个不同格式片段的匹配可能无法一次命中。

没有新增实时协作、自动历法换算、逐字修订对比或独立附件存储。发布前建议在测试课题中使用真实账户复核保存与导出；此次改版未发布到线上，也未迁移或修改真实云端数据。

## 极简视觉更新

本轮按最新设计方向替换报刊式的大刊头与重装饰，使用轻量导航、统一线条图标、柔和中性色、紧凑工具栏与一致的控件间距。图标均在本地生成，不依赖外部图标服务。

首页在手机上呈现自适应课题列表，编辑工具栏可横向滚动；低频阅读外观控件收进菜单。新增 `pnpm test:ui`，验证 360、390、768、1024、1440 像素下的布局、可见表格边界与编辑控件。

## 阅读优先布局与字体

标题栏为桌面 48px、手机 44px。阅读模式的目录与批注默认宽度为 144px、172px，可用正文右上角的按钮收起。手机默认收起两侧面板，选择目录条目后自动回到正文。阅读模式展示全部筛选结果，因此隐藏无效的底部分页；列表等模式保留紧凑分页。工作台卡片视图已移除，旧偏好自动回到列表。

中文默认使用随站点提供的思源宋体（Adobe Source Han Serif CN VF）；英文和数字使用 Arial 无衬线字体。字体按 Unicode 分包，常用字约 1.2 MB，其他字符按需加载，保留原字体的 29,796 个 CJK 编码字符。文中手动设置的格式继续保留。

切换条目、展开面板、按钮反馈加入轻量动画，并遵循系统的减少动态效果偏好。`pnpm test:reading` 验证阅读比例、面板操作、旧偏好兼容和浏览器实际使用的中英文字体。

字体源文件：[Adobe Source Han Serif CN VF](https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/Variable/WOFF2/OTF/Subset/SourceHanSerifCN-VF.otf.woff2)。分包脚本 `scripts/subset_research_font.py` 需要 fonttools 与 brotli，运行时传入原字体路径。普通预览无需重新生成字体。许可证见 `licenses/Source-Han-Serif-OFL.txt`。

## Apple 官网风格更新

参考 Apple 官网的简洁视觉层次，采用白色、浅灰色和深黑色作为主色，蓝色只强调主要操作与选中状态。统一胶囊形主按钮、柔和圆角、细分隔线、轻微阴影及半透明标题栏。首页、工作台、编辑器和登录页保持同一套视觉规范。

继续保留思源宋体中文、Arial 英文、48px／44px 紧凑标题栏及阅读正文优先布局。没有使用 Apple 标志、产品图片或专属字体。参考地址：https://www.apple.com.cn/ 。
